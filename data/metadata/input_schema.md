# Input contract

Input: old/new maps keyed by exact outcome identifier, with text, version and locator; mappings is a list of [old_id,new_id] relationships. source_sha256 records all three originals. Parser reads CSF 1.1 sheet1 column C, CSF 2.0 sheet2 column C and crosswalk sheet1 columns A/C. Inventory guards require 108/106 outcomes. Bundled demo contains the complete derived Core outcome inventories and NIST crosswalk relationships; third-party informative references are excluded. One-sided candidates cite the existing outcome; the missing side is explicit and is not fabricated.
